# Deviation log

RULES.md §5 names this path for the deviation log. This project's log was written as
[`../DEVIATIONS.md`](../DEVIATIONS.md) before that convention was applied to it, and it is **frozen
there** as part of the v0.3 release (`RELEASE-v0.3.md` lists it with its checksum). It was not moved,
because moving it would change files inside a tagged, checksummed release for the sake of a filename.

- **Rounds 1-6, up to and including the v0.3 freeze:** [`../DEVIATIONS.md`](../DEVIATIONS.md).
- **Everything after the v0.3 freeze:** recorded below, in the same numbered, dated form.

There is no pre-registration to deviate *from* — see
[`../prereg/NO-PREREGISTRATION.md`](../prereg/NO-PREREGISTRATION.md). The entries in both files are
therefore changes of analysis or claim against the previously committed state, not departures from a
frozen plan.

## Superseded numbers

RULES.md §5 asks that superseded numbers be reconciled rather than silently replaced. For this
project the reconciliation lives in two places:

- `DEVIATIONS.md` gives old → new values with the reason, per round.
- `src/compare_builds.py` holds the machine-readable form: each declared difference between builds
  is named with the change that caused it, and the comparison **fails** if a declared difference
  does not actually occur. A difference nobody declared is reported as unexpected.
